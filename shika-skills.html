バックキャンセル

コマンド

説明

入手場所


ダッシュすら差し置いての連番トップのスキル。

前作のレーヴァテインでのみ使用できたアクションが本作では通常攻撃で自在に使用できる。

空中でも使用でき、その場合はホップせず後退のみする軌道になる。

事実通常攻撃の硬直はそこそこ長いのでそこに割り込む恩恵は大きくも見えるが、

バックステップ自体も大概似たような行動制限がかかるので言うほどダメージ効率が上がるアクションではない…

むしろ後退したせいで逆に余計なダメージをもらったりと傷口を広げる事態になる場面も少なくない。

およそ闇雲に発動してよいものではなく、非常に扱いの難しいアクションスキルであると言わざるを得ない。


振り終わりに↓を入れるだけで発動してしまうので誤爆の機会も少なくなく、

特にホーリーチャージとコマンドが被っているので、連続でチャージしたいような場面ではこれがあると逆に効率が落ちる。

鬱陶しく感じるようであれば潔くオフにしてしまう選択もありである。

ぶっちゃけ最終盤までは使っても使わなくても大勢に影響はない。


なおこのスキルが真価を発揮するのは最後のスキルであるリボルバーを入手して以降であり、

天国攻略に至る最終的には必須となるアクションスキルではある。



ダッシュ

コマンド

説明

入手場所


あって当然なアクションスキル。前作ですら標準装備のこのアクションでさえ本作の最初期は持ち合わせていない。

もうそりゃ只の黄色い子鹿じゃん…

ダッシュをトリガーとするアクションは山のように存在するあたり、ハイスピードアクションの起点と言えるスキル。

方向キー2回というコマンド自体が古臭いだの度々誤爆するだのネガティブな評価が後を絶たない印象だが、

これを受け入れられなければシリーズを攻略していくことは不可能である。

Steam版では入力の有効フレーム幅を変えられるようになったりと制作サイドからも多くのケアが行われている。

誤爆を避けたい場面での左右移動は斜め下入力で行うと(低速移動は発動するが)確実に封印できる。

また発動中のダッシュは反対方向を入れることでいつでもキャンセルでき、

プレイヤーの認識の範囲内でなら案外融通が利く性能となっている。



リサーチ

コマンド

説明

入手場所


最後にダメージを与えた敵の残HP(＋最大HP)が画面上に表示される。

敵の最大HPが100以下なら、最大HPについても判別できる。

残HPが100以上の場合、次の色のゲージが重ねて表示される。

ダッシュと同様に最初期に手に入るので、本作においてはあるのが前提のスキル。

前作では敵の残HPを知る術はなかったので順当に進化している要素と言える。

スラッシュ

コマンド

説明

入手場所


ダッシュジャンプ中の通常攻撃が360度回転攻撃に置き換わる。

ただ悲しきかな、派手めで格好良いモーションの割に攻撃判定は心底スカスカで見掛け倒しという印象が強い。

一応ホーリーチャージ付きの場合、Iframeが大きく短縮され一振りで最大4ヒットする。

ただしトンファーと同様、そこまで出すには相手にしっかり重なる必要がある。重なれない状況では精々2ヒットが関の山。

大抵の場合、チャージを消費して撃つには効率が悪すぎるので空中ダッシュからのダッシュアタックに軍配が上がる。

効果的に使えるのはタワー君のⅢ形態ぐらい。

マナドレイン

コマンド

説明

入手場所


通常攻撃一発につき、内部値で3(ゲージ1/10)のMSを回復できるようになる。

これさえあればステージの佳境においてMS空っぽ状態で通常殴りをチマチマ繰り返すような悪夢を見ずに済むようになる。

MSは有限という前提条件を覆し、中盤以降のゲーム性を転換していく立役者。

MSの重みが大きく軽減され、ステージ全体を考慮するような面倒なMS管理やケチケチしたウェポン運用も不要となる。

精神的な負担もかなり減るので、長丁場なステージやHPの多いボスが登場し始めるまでには必ず取得しておきたい。



グライド

コマンド

説明

入手場所


左右入れっぱなしでダッシュ距離が無限遠に伸びるようになる。

地続きの地形であることが継続条件のようで、崖で惰性落下したり壁に接触するとそこで効果は中断される。

ダッシュの項の通り、キャンセルに関しては自在のため進みすぎるという事態はまず起こらない。

ダッシュの速度は駆け終わりにジャンプすればより長く維持できるのでそれで事足りる場面も多いが、

あって困ることはないシンプルに便利な補助スキル。



空中ダッシュ

コマンド

説明

入手場所


接地を挟む1回のジャンプの間で1回だけ可能であり、グライドは無効である。

一段目のジャンプ中に行い、ダッシュ後に二段ジャンプをすることも可能。

一段ジャンプでは届かない高さでスラッシュを撃つこともできたりと、かなり複雑な空中制御を実現できるようになる。

より高さを稼げるハイジャンプからの二段ジャンプなどは横移動速度に難があるので、このアクションの重要性は非常に高い。

飛距離を伸ばすだけでなく、滞空時間を稼ぐ用途としても重宝する。



ダッシュアタック

コマンド

説明

入手場所


判定が縦に少し太くなる他、Iframesが短くなって一撃あたり最大2ヒットするようになる。

また地味に飛距離も伸びているようである。

後述のホーリーチャージによるチャージ状態を重ねると更に性能が上がる。

これの入手以降は、身動きの取れない状況でない限り通常攻撃はダッシュ中に行うのが鉄板となっていく。

空中ダッシュとの組み合わせも有効。

ダッシュジャンプ中の通常攻撃には適用されない。そちらはスラッシュの領分になる。



ホーリーチャージ

コマンド

説明

入手場所


ダッシュ無しでもダッシュアタックと同等の攻撃性能になる。

ただチャージの硬直が結構長く、咄嗟の回避が間に合わないケースは数知れず。

チャージ状態でダッシュアタックを組み合わせると更に攻撃が太くなり、一撃あたりのヒット数は最大5ヒットまで強化される。

通常攻撃のDPS、すなわちMS回復効率は圧倒的なものとなるため、

是が非でもダッシュアタックと組み合わせて運用したい。

アクセラレート

コマンド

説明

入手場所


戦争編終結後に解禁される、ハイスピードアクションの象徴的スキル。

本家メトロイドヴァニアで言う所のブラックパンサーやイニレ・ラピドゥスに相当するお役立ち高速移動アクション。

これ無しで終結後の裏世界編を進むなんて。とてもよくないです。

ダッシュを含め、横方向の移動速度が大幅に上昇する。ダッシュは単位あたりの移動量も大きく伸びる。

アクションボタンの出番はこのスキル入手後からが本領である。

使用自体には何のペナルティも無いので、以降はこの速度が標準となっていく。

ただしウィング・低速移動とは併用できず、こちらが優先される。精密移動を要する場面ではきっちり解除が必要。



ウィング

コマンド

説明

入手場所


落下中にジャンプボタンをホールドすると非常にゆっくり降下する。

高度を維持することはできない。縦方向専用の低速移動スキルという見方もできる。

接地するタイミングを柔軟に計れるようになり、落下時の隙を大きく軽減できるようになる。

アクセラレートと並び終盤のアクションの要となるスキル。

地上から長時間離れたい場面はもちろん、これを使っているだけで避けられる攻撃もあったりする。

コマンド入力を要する空中ダッシュの精度を高める補助的な役割としてだけでも結構大きい。

ただしアクセラレートとは併用できず、アクションボタンを押下すると消失してしまう。

また発動中はウィングが優先され、急降下は使用できない。

急降下したい場合は一度↓を放し、ジャンプボタンをホールドしてから再度↓を押下する必要がある。


グレートクリア報酬なので取得は任意だが、

どの道エレレレ裏世界編解放のトリガーとなる「生命のマナ」では必須となるアクション。

マリ専用の秘奥義。

威力消費共にハイリゲの約2倍相当となっており、MS消費効率は似たり寄ったり。

秘奥義中は無敵だが、優秀な射程を活かして十分な距離を取った上で安全に使用したい。



マリチャージ

コマンド

説明

入手場所


「万能属性」含め、マリ専用のスキル。

通常攻撃の地獄の槍の一連撃、または二連撃目の振り終わりにコマンドをホールドすることでチャージが発動する仕組み。

三連撃目では発動しない。

チャージ攻撃は威力が上がる他、振り始めまでに僅かな硬直が発生するが振り終わりまで滞空性能も付く。

万能属性は以降の鹿編でも登場しないため、

結局は神ハローのレインボー・バリアを突破するためだけに存在する要素となっている。


チャージで隙を晒すのは事実なので、それ以外で使うか使わないかは好みのレベル。

ぶっちゃけ普通の槍で刺しまくるのが一番隙なく堅実に強い、というのが幼女なのであった。



アップドラフト

コマンド

説明

入手場所


アクションボタンの押下により、二段ジャンプ以上の高度を誇る超ハイジャンプを繰り出す。

このアクションからは更に二段ジャンプには繋げられない。空中ダッシュは使用可能。

またダッシュジャンプの代わりに発動することもできないが、性質上アクセラレートが同時発動するため横移動は初動からそこそこ速い。

初速は物凄いが、無敵等は一切付かず移動アクションの域を出ない。


なお言うまでもない話ではあるが、このゲームはより高く跳べれば良いというような単純なものではないため

断じて既存のジャンプや二段ジャンプに取って代わるアクションではない。

唯一の「ジャンプボタン以外でのジャンプ行動」であり、本音を言えばかなり習熟に労力を要する操作である。

アクセラレートの切り替え時に暴発することも度々あり、ジャンプ押してないのに勝手にジャンプしやがるという現象は

やらかすと結構ストレス性が高い。終盤の弾幕が苛烈な戦場ではほぼ確実に余計な被弾に繋がってしまうし尚更である。

これでなければ回避できないものは天国までは存在しないので、事故がウザいなら暫くはオフにしてしまってもよい。


しかしSteam版追加要素(神殿・天国)に挑む際には極力このアクションスキルも使いこなせるようにすべきである。

特に天国のカオスの残り火はこれが無いと回避不能の攻撃パターンを繰り出すため、最終的にはオンにせざるを得ない。

EXリミットブレイク

コマンド

説明

入手場所


Steam版追加スキル。

強大なHPインフレを起こす天国コンテンツ向けの調整措置。

1体撃破時点で一気にそれまでの1.5倍以上に、最終的には天国挑戦前の2倍のHP量になる。

最大まで成長させるには天国の半分のメンツを撃破する必要がある。

スキル自体が成長するという特例の仕様のため、丸ごとオン／オフの制御しかできない。

これを未所持の初戦が厳しいのは事実だが、これがあるからといって楽々攻略などとは行くわけもないのが天国である。


地味に先生編・マリ編にも適用される。戻ってプレイする機会はまずないだろうが。



リボルバー

コマンド

説明

入手場所


Steam版追加スキル。

唯一のスキルツリー報酬の形で入手できるスキル。スキルツリーなのに。

最後に入手することとなるスキルだが、獲得条件は炎のドスコイ力士の高速撃破とハードル高めである。

バックキャンセルをするだけでチャージ済状態になる。空中攻撃からのキャンセル時でも問題なく発動する。

ホーリーチャージに必要なコマンド入力＋硬直が丸ごと省略できることになり、

チャージダッシュアタックの回転効率は倍近いものとなる。

入手以降はホーリーチャージはほとんどお役御免となる、ほぼ上位互換な性能。


MS回復効率が更に爆上がりするため、最終的には使いこなすことが必須。

誤爆が鬱陶しいバックキャンセルを封印しているプレイヤーも、これの入手を受けては渋々引っ張り出さざるを得ない。
